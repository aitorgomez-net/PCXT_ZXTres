Basics

Using the OSD

The menu is drawn by the core over the picture, 32 columns wide. A line under the title shows the machine, the CPU speed and the card in use; a help line at the foot explains the entry under the cursor.

  • Cursor keys move; Enter opens a page, runs an action or steps an option; left and right step an option back and forth.
  • Esc backs out of a page and, from the main page, closes the OSD. The keyboard does not reach the machine while the OSD is open.
  • The machine, the PC/XT card, the CPU type, the PCjr RAM and new hard disks wait for Reset & apply; the other options act at once.
  • Changes last until power-off unless Save settings writes them to PCXT.CFG.

Below, a [condition] marks an entry that is shown only then. "PC/XT", "Tandy" and "PCjr" are the machine in use; "CGA/HGC" and "EGA" the PC/XT card (the Tandy 1000 and the PCjr count as CGA).

Video and Output

  • Video
    • — Card — [PC/XT]
    • Video card CGA/HGC · EGA [PC/XT, full core]
    • Monitor 5154/ECD · 5153/CGA · 5151/MDA [EGA]
    • 1st video CGA · Hercules [PC/XT, CGA/HGC]
    • CGA graphics / HGC graphics Yes · No [PC/XT, CGA/HGC]
    • — Picture —
    • Display Full Color · Green · Amber · B&W · Red · Blue · Fuchsia · Purple
    • Composite Off · On [CGA]
    • Border No · Yes [CGA]
    • Border CRT offs No · Yes [CGA]
    • Frame stacking Native · Rebuilt [CGA]
    • Output
      • — Position —
      • CRT H offset 0–15; CRT V offset 0–7
      • — Output —
      • Scandoubler Auto · Off
      • 350-line CRT 480p 31 kHz · Native · 480i 15 kHz · 240p 15 kHz
      • — Boot splash —
      • Splash time 5 s · 10 s · 15 s · 0 s
      • Video info — the picture the machine draws and what leaves the VGA pins, measured live
  • 1st video tells the BIOS which card is the first display when CGA and Hercules are both present; F11 swaps the output between them. CGA graphics and HGC graphics remove a card from the machine.
  • Display tints the RGBI picture; Composite enables the simulated NTSC colour decoder of the CGA.
  • Frame stacking: Rebuilt shows on a stable raster the per-scanline CRTC tricks (such as the water of the Area 5150 end credits) that need CGA-exact timing the core does not reach. Native runs them on the CRTC as written.
  • Scandoubler: Off sends the 200-line modes at 15.7 kHz. 350-line CRT chooses how the 350-line EGA and Hercules modes leave the board: 720×480 at 59.94 Hz (the default), the card's own raster, or 15 kHz interlaced or progressive.

    • — Levels —
    • Speaker Volume 1–4; Audio Boost No · 2x · 4x; Stereo Mix none · 25% · 50% · 100%

C/MS and the Sound Blaster Pro share 220h and collide on 226h/227h, so Audio 220h enables one of them. In the ZXTRES PC/XT builds, which have the Sound Blaster but no C/MS, the C/MS value leaves 220h empty. Tandy Sound adds the SN76489 to a PC/XT; the Tandy 1000 and the PCjr always have it.

Hardware

  • Hardware
    • — CPU — [not PCjr]
    • CPU Type 8088 · 8086; Fake 286 FLAGS Off · On; BIOS Writable None · EC00 · Main · All [not PCjr]
    • — Memory —
    • EMS D000-DFFF Enabled · Disabled [not PCjr]
    • UMB C400-CFFF Enabled · Disabled [build with it, not PCjr]
    • A000 UMB Enabled · Disabled [CGA, not PCjr]
    • PCjr RAM 128K … 640K [PCjr]
    • — Joysticks —
    • Joystick 1 / Joystick 2 Digital · Analog · Off
    • Sync to CPU No · Yes [not PCjr]; Swap Joysticks No · Yes
  • CPU Type selects the 8088 or the 8086 bus; Fake 286 FLAGS helps software that probes the reserved FLAGS bits.
  • BIOS Writable lets software write to the EC00 ROM, the system BIOS or both (some utilities patch them).
  • The EMS is a 2 MiB Lo-tech board, frame at D000h, ports 260h–263h (driver: hdd/LTEMM-r01). A000 UMB maps RAM at A0000h while the CGA/Hercules card is in use; UMB C400-CFFF maps RAM behind the EGA BIOS.
  • The DB9 pads are digital; Analog is kept for completeness.

At start the firmware loads PCXT.ROM, TANDY.ROM, EC00.ROM, EGA.ROM and PCJR.ROM from the PCXT folder, or the files saved in PCXT.CFG, with the machine held in reset. A file chosen here is loaded at once and the machine restarts. Cartridges are not saved; a cartridge entry that holds one offers Unmount NAME.

ZXTRES (A35T)

The OSD of each build

A ZXTRES build has one machine and one card, so it has no Machine or Video card entry, and the entries of hardware it does not hold are hidden. The firmware is built with the build's profile; the status bits keep the same layout in every build, so a PCXT.CFG saved by one build is read by another.
